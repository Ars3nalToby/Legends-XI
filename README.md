# Legends XI

Two-player football legends game. Pick rival XIs (or snake-draft), then watch a seeded 22-player simulation in 3D with commentary and a pundit studio.

- `/` Head-to-Head (main game)
- `/solo.html` Solo XI builder and touch-controlled quick match
- `data.js` player database · `sim.js` match engine · `studio.js` commentary and pundits
